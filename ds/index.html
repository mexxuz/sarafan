Порядок блоков на экранах

Главная: первые шаги (по выбору на регистрации) → облако → поиск → анкета → охват → «вас ищут» (единственная синяя карточка) → свой круг → «Кого советуют ваши» → «Куда ходят ваши» → «Советуйте прямо в чате».
Поиск: заголовок → поле → круги → сколько нашли → карточки по кругам → «Спросить свою сеть».
Человек: шапка с местами работы → строки с лицами → как с ним работать → что о нём знают → о работе (общий блок, затем направления с лентой работ) → за что рекомендуют → рекомендации → какие места советует → кого рекомендует → действия внизу.
Моя сеть: круги во весь экран → приглашение → «кого здесь нет» → заявки → списки.
