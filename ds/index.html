Порядок блоков на экранах

Главная: шапка → круги знакомых → поиск → сферы → лента «Рядом с вами» → «Спросить свою сеть» → заявки → запросы → события.
Поиск: заголовок → поле → круги → сколько нашли → карточки по кругам → «Спросить свою сеть».
Человек: шапка → числа → как вы связаны → за что рекомендуют → рекомендации → кого рекомендует → действия внизу.
Моя сеть: круги во весь экран → приглашение → «кого здесь нет» → заявки → списки.
